🔄 Enhanced Archival Diplomatics Workflow

📋 Input → Processing → Output

🔹 INPUT (from Journalist/Frontend):
   • Video File (multipart upload)
   • Uploader Metadata (ID, timestamp, location)
   • Event Context (type, tags, description)

🔹 PROCESSING (Backend Workflow):
   1. SHA-256 Hashing → Digital Fingerprint
   2. Metadata Validation → Tamper Detection  
   3. IPFS Storage → Decentralized Storage
   4. Blockchain Registry → Immutable Proof
   5. Neo4j Graph → Relationship Mapping

🔹 OUTPUT (to Frontend/Admin):
   • Verification Report (hash, validation)
   • Proof of Authenticity (IPFS CID, blockchain)
   • Graph Relationships (uploaders, events, locations)
   • Suspicious Pattern Analysis
   • Trust Score Calculation

🗄️ Neo4j Graph Schema

Nodes:
• (Video) - hash, ipfsCid, validation, metadata
• (Uploader) - id, totalUploads, lastSeen  
• (Event) - id, type, tags, description
• (Location) - id, name, coordinates

Relationships:
• (Uploader)-[:UPLOADED]->(Video)
• (Event)-[:CONTAINS]->(Video)  
• (Video)-[:RECORDED_AT]->(Location)
• (Video)-[:DERIVED_FROM]->(Video)
